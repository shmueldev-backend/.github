## Qué hay aquí

Esta organización concentra el **backend** de la marca: APIs, servicios, autenticación, acceso a datos y piezas listas para producción.

| Enfoque | Qué encontrarás |
| --- | --- |
| **APIs** | FastAPI, Django REST y contratos claros |
| **Datos** | SQL, capas de acceso y modelos de dominio |
| **Servicios** | Auth, reglas de negocio y orquestación |
| **Producción** | Estructura, pruebas y despliegue operable |

## Cómo se trabaja

1. Un repo = un servicio o un dominio claro.
2. README corto, contrato de API visible y entorno reproducible.
3. Mismo criterio visual y de código que el resto de SHMUELDEV.
4. Lo que no se puede operar, no se considera terminado.
